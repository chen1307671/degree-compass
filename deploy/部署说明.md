# 部署说明（Render · Docker）

## 一、上传到 GitHub

新建仓库（如 `degree-compass`），上传以下文件与目录：

```
Dockerfile
render.yaml
run.py
src/
reports/
raw/tables/
raw/manifest.json
```

**不要传** `assets/`、`slides/`、`交付/`（已在 .dockerignore 中排除）。

## 二、在 Render 创建服务

1. New → Web Service → 连接该仓库；
2. Render 自动识别 `Dockerfile`，Runtime 选 **Docker**；
3. Plan 选 Free（或 Starter，$7/月不休眠）；
4. 环境变量（可选，默认已写死）：
   - `AGENT_ACCOUNT=judge`
   - `AGENT_PASSWORD=learn2026`
5. Create Web Service，等 2–3 分钟。

## 三、验证

```bash
curl https://<你的服务>.onrender.com/api/health
# 期望：{"status":"ok","ready":true,"provinces":31}
```

浏览器打开首页 → 登录 `judge / learn2026` → 选「广东 / 初中 / 2030 / 基准」→ 应显示「紧缺 3.5 万」。

## 四、换链接

拿到公网地址后，把地址交给制作者，替换 PPT 第 16 页脚注与视频第 16 页字幕，重出两份文件即可。

## 五、注意

- 免费实例闲置 15 分钟休眠，首访约 30–60 秒唤醒；
- 容器内只有标准库，镜像约 120 MB，冷启动快；
- 数据文件随镜像打包，运行时不联网。
